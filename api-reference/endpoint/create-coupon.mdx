---
title: "Criar cupom"
api: "POST /v1/products/{productId}/coupons"
description: "Cria um novo cupom para um produto."
---

Requer o escopo `write` (além do `read`). Retorna `404` se `productId` não
existir ou não pertencer à sua conta. Suporta `Idempotency-Key` — veja
<a href="/rate-limits-and-idempotency">Limites de requisição e idempotência</a>.

<ParamField path="productId" type="string" required>
  UUID do produto.
</ParamField>

<ParamField body="code" type="string" required>
  De 1 a 50 caracteres. É salvo em maiúsculas, independentemente do que for
  enviado.
</ParamField>

<ParamField body="discount_type" type="string" required>
  `"percentage"` ou `"fixed"`.
</ParamField>

<ParamField body="discount_amount" type="integer" required>
  Número inteiro positivo. Percentual (0–100) se `discount_type` for
  `percentage`, centavos se for `fixed`.
</ParamField>

<ParamField body="usage_limit" type="integer">
  Número máximo de resgates. Omita ou envie `null` para ilimitado.
</ParamField>

<ParamField body="valid_from" type="string">
  Data e hora em ISO 8601.
</ParamField>

<ParamField body="valid_until" type="string">
  Data e hora em ISO 8601.
</ParamField>

<ParamField body="offers" type="string[]">
  IDs das ofertas às quais o cupom fica restrito. Omita ou envie um array
  vazio/`null` para aplicar a todas as ofertas do produto.
</ParamField>

<ResponseField name="data" type="object">
  Mesmo formato de um item do array `data` em <a href="/api-reference/endpoint/list-coupons">Listar cupons</a>.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.berrypay.com.br/v1/products/b1f2c3d4-0000-4000-8000-000000000001/coupons \
  -H "Authorization: Bearer bp_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7c1b8e2a-1c2d-4e3f-9a0b-1234567890ab" \
  -d '{
    "code": "welcome10",
    "discount_type": "percentage",
    "discount_amount": 10,
    "usage_limit": 100
  }'
```

</RequestExample>
