---
title: "Listar cupons"
api: "GET /v1/products/{productId}/coupons"
description: "Lista todos os cupons de um produto."
---

Requer o escopo `read`. Retorna `404` se `productId` não existir ou não
pertencer à sua conta.

<ParamField path="productId" type="string" required>
  UUID do produto.
</ParamField>

<ResponseField name="data" type="array">
  <Expandable title="cupom">
    <ResponseField name="id" type="string" />
    <ResponseField name="product_id" type="string" />
    <ResponseField name="code" type="string">Sempre em maiúsculas.</ResponseField>
    <ResponseField name="discount_type" type="string">`percentage` ou `fixed`.</ResponseField>
    <ResponseField name="discount_amount" type="integer">Percentual (0–100) se `percentage`, centavos se `fixed`.</ResponseField>
    <ResponseField name="active" type="boolean" />
    <ResponseField name="usage_limit" type="integer | null">`null` significa ilimitado.</ResponseField>
    <ResponseField name="times_used" type="integer" />
    <ResponseField name="valid_from" type="string | null" />
    <ResponseField name="valid_until" type="string | null" />
    <ResponseField name="offers" type="string[] | null">IDs das ofertas em que o cupom se aplica; `null` significa todas as ofertas.</ResponseField>
    <ResponseField name="created_at" type="string" />
    <ResponseField name="updated_at" type="string" />
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl https://api.berrypay.com.br/v1/products/b1f2c3d4-0000-4000-8000-000000000001/coupons \
  -H "Authorization: Bearer bp_live_xxxxxxxxxxxxxxxxxxxxxxxx"
```

</RequestExample>
